Una Empresa dedicada a la comercializaxion de productos tecnológicos necesita desarrollar un sistema
que permita administrar su catalogo de productos.

Actualmente la empresa utiliza una estructura secuencial para almacenar la información, lo que dificulta realizar buquedas, incersiones y eliminaciones cuando el numero de productos aumenta.
Cada producto deberá almacenarse en un NODO del Árbol. la organización seguirá la reglas de un árbol binario de búsqueda.

Objetivo: 
Desarrolar un sistema de administración de productos tecnologicos de abarrotes utilizando un árbol binario de búsqueda, aplicando los principios de abstracción,encapsulamiento y modularidad, asi como las operaciones fundamentales de insercion, busqueda, elminacion y recorrido de arboles
